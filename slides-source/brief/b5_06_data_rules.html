WIKI → 小本体 → 样本 → 独立评测WIKI → small ontology → samples → independent evaluation
  • 先统一 Back Order、Inventory、ETA、Service Promise、Priority 与 Action 等必要概念。Align essential concepts such as Back Order, Inventory, ETA, Service Promise, Priority and Action.
  • 90% 只作为待验证口径：必须写明任务、版本、分母、专家判定与失败分布，不能写成已达标。90% is a validation measure: define task, version, denominator, expert rubric and failure distribution; do not state it as achieved.
  • 回答、规则判断、预测、建议与 Action 成功率分开评估，高风险错误不能被平均值掩盖。Evaluate answers, rule judgments, forecasts, recommendations and action success separately; averages cannot hide high-risk errors.
