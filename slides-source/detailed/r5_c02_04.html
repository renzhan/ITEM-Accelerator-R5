证据：机制已有，收益待测Evidence: mechanisms exist, value pending

  • 权限ACCESSAgent 用用户委托的 WMS 令牌；角色无权限、任务未指派给本人，一律 403。The Agent uses the user's delegated WMS token; no role permission or a task not assigned to the user means 403.
  • 留痕AUDIT每次写入进入数据变更日志，并记录来自哪个页面的哪个版本。Every write lands in the data change log with the originating page and version.
  • 业务BUSINESSIssue 状态时间线、货况调整、取货/放货库存流水均可追溯。Issue timeline, condition change and take/place stock transactions are traceable.

待测：需求到首个可用版本的时长、迭代轮次、试运行缺陷、回退次数与采用率；当前没有可引用的生产 KPI，不得写成已实现。To measure: time from need to first usable version, iterations, trial defects, rollbacks and adoption; no citable production KPI exists yet.
