DAY 1 · MD §D1.2.3.7 · 可重复交付与动手DAY 1 · MD §D1.2.3.7 · Repeatable delivery and hands-on

现场把一条规则改完，并留下可验收草稿Change one rule live and leave an acceptance-ready draft

通用方法可以复用，业务语义必须重验证；动手目标是小范围草稿，不是宣称上线或正式报价成功。The method can repeat, but business semantics must be re-validated. The hands-on output is a bounded draft, not a production or formal-quote claim.

可重复交付链Repeatable delivery chain

01 · SCOPE授权数据与边界Authorised data and scope
02 · MODEL候选 → 审核 → 本体/规则Candidate → review → ontology/rule
03 · BUILD页面 → 表单 → 校验Page → form → validation
04 · PROVE正常/异常回放 → 人确认Normal/exception replay → human confirmation
05 · OPERATE验收 → 发布/回滚 → 反馈Acceptance → release/rollback → feedback

通用核心：审核、版本、溯源、异常分流、权限门、评测与维护。Common core: review, versioning, traceability, exception routing, access gates, evaluation and maintenance.

现场动手与停止机制Hands-on and stop rules

  • ISS Biz (team) 提供一条已授权、可脱敏的最小报价样本。
  • 修改一条业务规则/报价条件，展示本体定义、分析口径、表单校验、异常路径和权限门。
  • 产出：能力卡、小范围验收表、责任字段草稿。
  • 语义无法确认、样本不足、接口/权限不清或无法安全接管：缩小、转人工、暂停或停止。
  • ISS Biz (team) provides one authorised, redacted minimum quote sample.
  • Change one rule/quote condition; show ontology, analysis definition, form validation, exception path and access gate.
  • Output: capability card, bounded acceptance sheet and ownership fields.
  • If meaning, samples, interfaces, access or safe takeover fail: narrow, hand off, pause or stop.
