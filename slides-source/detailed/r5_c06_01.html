Item CCS：把企业知识接入 Genesys 客服流程Item CCS: connecting enterprise knowledge to Genesys service

我们已经具备 Genesys Cloud 集成能力，让来电、IVA（Interactive Voice Agent）、路由和坐席工作可以被监测、理解、更新和验证。We have integrated with Genesys Cloud so calls, IVA (Interactive Voice Agent), routing and agent work can be monitored, understood, updated and verified.

我们已经做了什么What we have built

  • 监测客户来电和问题趋势，识别持续出现的客户需求，而不是把偶然波动当成趋势。Monitor call and issue trends to identify persistent demand rather than treating every fluctuation as a trend.
  • 从企业知识库和 SOP 中起草 IVA 或坐席辅助内容，并保留来源依据。Draft IVA or agent-assist content from enterprise knowledge and SOPs, with the supporting source.
  • 在发布前进行风险检查，由人工决定是否发布、暂停或回滚。Run risk checks before release; people decide whether to publish, pause or roll back.
  • 发布后自动拨测，检查语音流程是否能正常走完，并把结果回写。Run automated test calls after release and write the results back for follow-up.

Genesys 与 Item CCS 的分工How Genesys and Item CCS work together

  • Genesys 承载客户沟通、IVA、路由和坐席工作。Genesys handles customer communication, IVA, routing and agent work.
  • Item CCS 增加监测、知识、判断、发布和验证能力。Item CCS adds monitoring, knowledge, decision, release and validation capabilities.
  • 我们不是重新建设一个呼叫中心，而是让现有平台能够持续改进服务流程。We are not rebuilding a contact centre; we make the existing platform continuously improvable.
