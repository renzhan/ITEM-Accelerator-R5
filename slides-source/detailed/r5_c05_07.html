可重复交付，先从一次安全动手开始Repeatable Delivery Starts with One Safe Hands-on Test

把方法拆成核心、配置、接口、评测和维护；现场只修改一个低风险规则或流程分支。Separate the method into core, configuration, interfaces, evaluation, and maintenance. Modify one low-risk rule or branch live.

通用交付 11 步11-step delivery pattern

  1. 筛选边界清楚、可复现的流程。Select a bounded, reproducible flow.
  2. 确认授权、数据、留存与停止条件。Confirm authorization, data, retention, and stop conditions.
  3. 录制/导入示例，提取步骤、条件、动作、例外、结果。Record/import and extract steps, conditions, actions, exceptions, results.
  4. 生成带证据与不确定性标注的 SOP。Generate an SOP with evidence and uncertainty labels.
  5. 业务审核 → 拆分 Agent/Tool/Workflow/人工步骤。Business review → split Agent/Tool/Workflow/manual steps.
  6. 沙盒跑正常/异常 → 受控发布 → 回写 → 回归。Sandbox normal/exception → controlled release → write-back → regression.

现场动手产出Hands-on outputs

选择低风险、可脱敏或模拟步骤，修改一条规则或流程分支，并保留修改前后版本。Choose a low-risk, de-identifiable or simulated step; modify one rule or branch and retain before/after versions.

  • 小范围 SOP 草稿/能力卡Small-scope SOP / capability card
  • 一个正常样本 + 一个异常样本One normal + one exception sample
  • 验收项、接管人、回滚条件Acceptance items, takeover owner, rollback condition
  • 责任人、审核人、版本与下一步Owners, reviewer, version, and next step
缩小/停止机制：证据不足、授权不完整、接口无法安全回写、异常不可控或无法验收时，保留人工、转交或停止；不强行产品化。Narrow/stop: if evidence, authorization, safe write-back, exception control, or acceptance is missing, keep human steps, hand off, or stop; do not force productization.
