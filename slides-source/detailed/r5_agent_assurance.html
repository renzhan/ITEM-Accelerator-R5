人工审核知识、自动化测试任务、第三方交叉评估，以同一套标准回答“如何证明可靠”。Human-reviewed knowledge, automated task tests and third-party evaluation provide evidence against one set of standards.

安全有边界，可信有标准Clear boundaries. Explicit standards for trust.

验收前由业务负责人明确：开放给谁、使用哪些数据与工具、允许执行哪些动作。Before acceptance testing, the business owner defines the users, data, tools and permitted actions.

安全可控Safe and controlled

仅使用授权数据与工具；高影响动作须预览并有效确认，取消生效后不得新增外部操作。Use only authorized data and tools. Preview and obtain valid confirmation for high-impact actions; no new external actions after cancellation takes effect.

知识可信Grounded in evidence

关键结论须有来源与证据支持；无证据、无权限或超范围时，应拒答或提示不确定。Support key conclusions with sources and evidence. Refuse or signal uncertainty when evidence or permission is absent, or the request is out of scope.

结果可验Verifiable outcomes

关键任务须留存执行记录与外部回执；核对参数、回执，以外部系统最终状态判定完成。Retain execution records and external receipts for key tasks. Check parameters and receipts; judge completion by the final external state.

验收通过条件Acceptance pass criteria红线事件为 0 · 必须项全通过 · 适用核心指标达标Zero red-line events · All mandatory checks pass · Applicable core targets met

人工把关，构建可信的知识基础Human review builds a trusted knowledge foundation.

业务专家与实施团队共同确认业务知识，为 Agent 回答与第三方评估提供依据。Business experts and the delivery team validate the knowledge used to ground agent answers and third-party evaluation.

真实来源Business sources

从业务数据、SOP 与真实操作中提取知识，保留来源。Extract knowledge from business data, SOPs and real operations, retaining its sources.

专家审核Expert review

业务专家审核知识内容，确认定义、规则与例外。Business experts review the knowledge content and confirm definitions, rules and exceptions.

验证发布Validate and release

用场景样本验证后发布，运行中的问题反馈给知识负责人。Validate with scenario samples before release; feed operational issues back to the knowledge owner.

知识沉淀Knowledge foundation经人工审核与场景验证，业务数据沉淀为语义确定性底座（Ontology）。Reviewed and scenario-validated business data forms an Ontology — a foundation of well-defined business semantics.

自动化测试，让验证持续、高效、可复用Automated testing: continuous, efficient and reusable.

固定测试用例与被测版本，形成可量化、可复验的测试记录。Fix the test cases and tested version to produce measurable, repeatable test records.

自动化执行与核对Automated execution and checks

  • 脚本批量执行，留存输入与输出Run scripts in batches; retain inputs and outputs
  • LLM 对照标准答案集（Gold Set）核对答案Use an LLM to check answers against the Gold Set
  • 复用用例与评估口径，变更后回归复验Reuse cases and evaluation criteria; rerun after changes
  • 业务人员介入评估Business users participate in evaluation

第三方交叉评估，多一重可信保障Third-party evaluation adds another layer of assurance.

已使用第三方 Evaluation Agent 评估输出与执行过程；争议与高风险结果由人工复核，业务负责人依据证据验收。A third-party Evaluation Agent has assessed outputs and execution. People review disputed or high-risk results; the business owner accepts the work based on evidence.
