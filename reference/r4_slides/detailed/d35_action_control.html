从建议到执行的责任边界The accountability boundary from suggestion to action

工具返回不等于业务完成；权限、审批、幂等、重试和冲突必须成为运行条件。A tool response is not business completion; permissions, approval, idempotency, retries and conflicts are runtime conditions.

查询Query

  • 读取也要受权限、敏感信息和来源约束。
  • 明确返回时点、范围和证据。
  • Reads still require access, sensitive-data and source controls.
  • Define return time, scope and evidence.

写入Write

  • 高风险动作需要人工确认或审批。
  • 设置幂等、重试、冲突处理和回滚。
  • High-risk actions need human confirmation or approval.
  • Set idempotency, retry, conflict handling and rollback.

完成Completion

  • 日志记录工具结果与业务实际结果。
  • 异常必须接管，责任人可追溯。
  • Log tool result separately from actual business result.
  • Exceptions require takeover and traceable ownership.
