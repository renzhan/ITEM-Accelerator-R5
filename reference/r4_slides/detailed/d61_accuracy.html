MD §D1.4.1 · Agent 输出准确性

准确性：以任务、风险和证据定义门槛Accuracy: Define the Gate by Task, Risk and Evidence

“90%”不能脱离任务、分母、版本和风险谈；正确率只是质量的一部分。“90%” has no meaning without task, denominator, version and risk; accuracy is only one quality dimension.

按任务拆开Split by task

  • 检索/回答、规则判断、分类、预测、方案建议
  • 实际执行分别定义输入、输出和完成条件
  • Retrieval/answer, rules, classification, prediction and recommendation
  • Define input, output and completion per task

按证据评测Evaluate evidence

  • 独立样本、正常/异常/边界、专家判定、版本记录
  • 失败分类、覆盖率、缺失信息、响应时间与成本
  • Independent samples, normal/exception/boundary, expert labels, versions
  • Failure classes, coverage, missing information, time and cost

按风险设门Gate by risk

重点看高风险失败；系统要能引用来源、澄清、拒答、回退和升级，不能靠模型自评。

Inspect high-risk failures; the system must cite, clarify, refuse, fall back and escalate. Self-rating is not proof.

决策输出Decision output首个场景的评测对象、分母、指标、错误等级、人工确认和上线门槛；BO 90% 口径回到 §D1.2.4。Define the first scenario’s evaluation object, denominator, metrics, error levels, human confirmation and release gate; BO 90% returns to §D1.2.4.
