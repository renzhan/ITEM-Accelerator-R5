本轮保留 90% 作为重点讨论和验证值；当前源材料没有提供已实现结果，因此不能写成整体上线准确率。Keep 90% as a key discussion and validation value; the source provides no achieved result, so it cannot be presented as an overall production accuracy.

90%

本轮验证目标，除非补齐证据Validation target unless evidence is supplied

必须同时给出任务类型、场景、版本、正确数/有效样本数、专家口径与失败分布。State task, scene, version, correct/valid sample count, expert definition and failure distribution.

不能混成一个平均数Do not collapse into one average

  • 专家审核通过率 ≠ 回答准确率Expert approval rate ≠ answer accuracy
  • 规则判断 ≠ ETA 预测 ≠ Action 成功率Rule judgement ≠ ETA prediction ≠ Action success
  • 训练/调试样本与独立评测集分开Training/debug samples stay separate from independent evaluation
  • 高风险错误不能被平均准确率掩盖；执行还看权限与人工确认Average accuracy cannot hide high-risk errors; execution also needs access and human confirmation

若已有实测，展示正确案例数/有效评测案例数；若没有，明确标为目标。If measured, show correct cases / valid evaluation cases; otherwise label it as a target.
