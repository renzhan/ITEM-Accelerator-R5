代码到本地运行，再到自定义页面From code to local runtime to custom page

生成只是中间动作；完整链路要证明页面理解既有 WMS，并能被校验、测试、审核后受控发布。Generation is only an intermediate step; the full chain must prove that the page understands WMS and can be validated, tested, reviewed and released with control.

01 · CONTEXT

WMS 代码WMS code

读取结构、字段、组件、权限与接口约定。Read structure, fields, components, permissions and interface conventions.

02 · RUN

本地环境Local environment

用可复现流程和样例数据运行。Run a reproducible flow with sample data.

03 · GENERATE

自然语言需求Natural-language need

生成一致的页面、字段与交互。Generate aligned page, fields and interaction.

04 · CHECK

校验 ActionValidate Actions

补字段校验、权限、错误处理与状态更新。Add validation, access, error handling and state updates.

05 · RELEASE

审核发布Review and release

代码审核、构建、功能/接口测试后发布。Release after code review, build, functional and interface tests.

建议现场演示Suggested live demo

从仓库异常需求开始，展示一次完整的需求描述、代码生成、本地运行、业务修改、测试与状态回写。Start with a warehouse exception need; show the full sequence of requirement, generation, local run, business change, test and state write-back.
