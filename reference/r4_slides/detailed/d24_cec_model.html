MD §D1.2.6 · Day 1

自有模型要解决已证明的质量或成本缺口Own models need a proven quality or cost gap

先把任务、授权与现有能力跑稳，再决定是否训练；eSVC 只是候选，不是既成能力。Stabilize the task, access and existing options first; eSVC is a candidate, not an existing capability.

决策顺序Decision order

  • 先检索知识、规则与 Prompt 路由。
  • 再比较现有小模型、适配或人工辅助。
  • 只有缺口被证据证明，才评估自有模型。
  • Start with knowledge, rules and prompt routing.
  • Then compare existing small models, adaptation and human assist.
  • Assess an own model only after evidence proves a gap.

CEC 候选边界CEC candidate boundary

  • eSVC 可作为分类、意图或路由候选。
  • 情绪识别等具体目标仍需确认。
  • 外部产品化、数据/IP 与责任另行评估。
  • eSVC may be a candidate for classification, intent or routing.
  • Specific targets such as sentiment still need confirmation.
  • External productization, data/IP and ownership need separate review.
