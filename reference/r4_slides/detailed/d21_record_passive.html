MD §D1.2.5｜被动知识采集与授权MD §D1.2.5 | Passive capture and authorisation

被动知识采集必须先划定授权边界Passive knowledge capture starts with consent

全方位录屏是未来可验证方向，不是当前默认承诺；减少填写负担不能绕过告知、授权和最小化原则。Broad recording is a future validation direction, not a current promise; reducing input burden cannot bypass notice, consent and minimisation.

先确认四组边界Confirm four boundaries first

PURPOSE采集目的与使用范围Purpose and use scope
CONSENT用户、电话与屏幕授权User, call and screen consent
MINIMISE屏幕范围与敏感信息Screen scope and sensitive data
STOP停止条件、权限与审计Stop conditions, access and audit

采集、处理、留存分开决定Separate capture, processing and retention

  • 采集/处理：提取步骤、结构化记录和审核结果。Capture/process: extract steps, structured record and review result.
  • 原视频：是否临时缓存、抽检、回放、保留多久，另行确认。Raw video: decide separately on cache, sampling, replay and retention period.
  • 部署：Edge Server 不是硬承诺，环境由业务、安全和审批方确认。Deployment: Edge Server is not a hard promise; business, security and approvers decide.
  • 执行：知识形成后，Action 仍需权限与人工接管。Execution: even after knowledge capture, Actions need access and human takeover.

被动采集不是未经告知的监控。Passive capture is not covert monitoring.
