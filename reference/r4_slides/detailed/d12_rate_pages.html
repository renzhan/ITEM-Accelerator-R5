MD §D1.2.3｜分析页面与应用表单MD §D1.2.3 | Analysis page and application form

同一本体连接分析页面与应用表单One ontology connects analysis and action

同一套定义要贯穿“看懂数据”和“做出动作”：规则修改应同时影响分析口径、表单校验与正式报价权限。The same definitions should govern understanding data and taking action: a rule change should affect analysis, form validation and formal-quote access together.

分析页面：解释结果从哪里来Analysis page: explain the result

本体与口径Ontology and definition

对象、条件、有效期与来源可追溯。Objects, conditions, validity and source are traceable.

→

业务观察Business view

看到条件影响、结果和缺失信息。See condition impact, result and missing information.

页面不是另起一套业务定义，也不是只给报表。The page is not a second definition set or a reporting-only surface.

应用表单：把规则带进执行Application form: carry rules into action

  • 根据同一本体生成字段与校验。Generate fields and validation from the same ontology.
  • 报价建议与正式对外报价分开授权。Separate quote suggestions from formal external quotes.
  • 异常条件与缺失信息进入人工判断。Route exceptions and missing information to human judgement.
  • 实际使用与业务结果反向更新本体和规则。Feed usage and business results back into ontology and rules.
