工单变成无头 Agent 的执行链From ticket to headless Agent execution

无头 Agent 由事件、工单或状态变化触发，按明确权限在后台运行；关键确认、异常与高风险动作始终有人的入口。A headless Agent is triggered by an event, ticket or state change and runs under explicit permissions; confirmation, exceptions and high-risk actions retain a human entry point.

正常路径｜后台执行Normal path | background execution

输入完整、状态一致、动作在授权范围内：自动推进并更新业务状态。Complete inputs, consistent state and authorised actions: proceed and update business state.

异常路径｜人工接管Exception path | human takeover

数据缺失、状态冲突或高风险动作：暂停、保留上下文、交给 Owner 判断。Missing data, state conflict or high-risk action: pause, preserve context and ask the Owner to decide.
