案例之后看架构：单一入口不是单一聊天窗 After the cases: one entry is not one chat window

统一身份、任务、结果和异常处理；现有 WMS、Genesys、ISS 仍可作为业务工作面。 Unify identity, tasks, results and exceptions while WMS, Genesys and ISS remain business work surfaces.

从输入到行动 From input to action

业务输入 Business input → 语义与知识 Semantics & knowledge → Data / Model / Tools → Agent / Workflow → 受控执行 Controlled action → 平台与能力回写 Platform & capability writeback

入口要回答的问题 Questions the entry must answer

  • 当前任务、依据的事实、建议原因、待确认事项、执行结果和查看位置。
  • 统一入口不等于强迫所有工作进入聊天；接口和运行记录才是连接点。
  • What is the task, which facts were used, why this recommendation, what needs approval, and where is the result?
  • One entry does not force all work into chat; interfaces and run records are the connection points.
